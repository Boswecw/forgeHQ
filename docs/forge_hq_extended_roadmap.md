# ForgeHQ Extended Roadmap

Date: 2026-04-26

## Purpose

This document preserves the extended ForgeHQ roadmap surface required by the documentation protocol gate.

ForgeHQ remains a governed shaping and proposal-packaging service. It receives upstream evidence references, ranks candidate targets, packages reviewable proposal surfaces, and preserves operator review boundaries.

## Current Roadmap Position

Phase 06 adds the evaluation-spine proposal bridge. ForgeHQ may reference upstream Forge Eval, Eval Calibration Node, and ForgeMath artifacts, but it must not recalculate upstream confidence, thresholds, rollback posture, or authority decisions.

## Near-Term Direction

1. Preserve upstream evidence lineage.
2. Package proposal-ready references for operator review.
3. Keep proposal shaping separate from evaluation authority.
4. Maintain documentation protocol surfaces as first-class control artifacts.
5. Continue adding deterministic tests before expanding behavior.

## Boundary Notes

ForgeHQ is not the evaluation authority. It is not the math authority. It is not the operator approval authority.

ForgeHQ packages governed proposal context from validated upstream evidence.

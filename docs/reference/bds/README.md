# BDS Reference Protocols

This directory stores imported company-core doctrine that informs `forgeHQ` work but is not itself the repo-local source of truth.

## Boundary

- Repo-local implementation truth lives in `doc/system/`, `SYSTEM.md`, `CLAUDE.md`, and repo-specific docs under `docs/`.
- Files in this directory are cross-ecosystem reference doctrine.
- These references should not be confused with forgeHQ-specific contracts unless they are explicitly adopted into repo-local docs.

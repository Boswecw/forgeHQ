# Non-Authoritative Language Policy

forgeHQ artifacts must speak in non-authoritative proposal language.

## Allowed language

- propose
- hypothesize
- suggest
- indicate
- candidate
- challenge
- observed candidate gain
- reviewability state
- residual concern

## Prohibited language

- approved
- confirmed fix
- proven truth
- authoritative state
- must apply
- merge now

## Hard rule

Every forgeHQ artifact must carry explicit non-authoritative posture.

The code-level helpers in `app/domain/reviewability/enums.py` provide the initial governance validators for allowed and prohibited language scans.
